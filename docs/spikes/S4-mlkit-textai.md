# S4（結果）：ML Kit による翻訳・校正の試作

## 1. 目的と決まったこと
- 翻訳（Translation API、Prompt API）と校正（Proofreading API、Prompt API）の動作を試作し、制約と挙動を確認しました。
- 試作では「巨大なモデルの勝手なダウンロードはしない」という原則に従い、ダウンロード済みのモデル（Translation API）のみ実行し、他のモデル（Prompt API, Proofreading API）の動作は「ダウンロードが必要」というステータスの確認にとどめました。

## 2. 品質（人間の評価）
- **翻訳（Translation API）**
  - ko→ja (Sample Transcript):
    - 「안녕하세요. 만나서 반갑슴니다.」 -> 「こんにちは私はあなたに会います。」（直訳調だが動作確認は成功）
    - 「이건 얼마에요?」 -> 「これはいくらですか？」（正しい翻訳）
    - 「저는 학생이에요.」 -> 正常に動作
- **その他（B, C, D）**
  - モデル未ダウンロードのため品質評価は未実施。

## 3. 速度
- **1チャンクあたりの時間**:
  - Translation API: 初回 約285ms、2回目以降 約45〜50ms と高速。
- **1レッスン（約300チャンク）通し時間**:
  - 未計測ですが、1チャンク50msと仮定すると、300チャンクで約15秒と推定されます。

## 4. 制約と挙動
- **モデルのダウンロード**:
  - Translation API はすでにダウンロード済みで即座に実行可能。
  - Prompt API (Gemini Nano) と Proofreading API は「モデルのダウンロードが必要です (DOWNLOADABLE)」と表示され、数百MB規模のダウンロードが必要なため今回は実施していません。
- **回数の上限 / 画面を消したときの挙動**:
  - Translation API については回数制限の明示的なエラーには遭遇せず、「全部を順に実行」はバックグラウンド動作の仕組みがUIに組み込まれています。Prompt API の BACKGROUND_USE_BLOCKED エラー等は本実装時の詳細検証となります。
