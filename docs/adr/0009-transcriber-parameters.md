# 0009. PC ツールのパラメータと、人間のレビュー待ちで保留する判断

- 状態: 提案（人間の承認待ち）
- 日付: 2026-10-14
- 決めた人: lead（スパイク S1 の結果をもとに）
- 根拠: [S1-pipeline-prototype.md](../spikes/S1-pipeline-prototype.md)（合成音声）、[S1-real-materials.md](../spikes/S1-real-materials.md)（実際の教材 3 本）
- 関係する節: 設計書 §7.4.4、§7.4.5

## 決定（いま決めるもの）

1. **候補チャンクをまとめる無音（`vad.merge_gap_ms`）は 100ms**（設計書 v0.5 の更新で反映済み）。300ms では、言語の切り替わりをまたぐ候補チャンクができ、
   Whisper がもう一方の言語に訳して書いた（合成音声で 90 件中 14 件）。実際の教材でも、発話の間の 10% 点は約 200ms で、100ms を維持する。
2. **文単位の整形で分ける無音（`chunking.split_gap_ms`）を 700ms → 400ms にする。** 実際の教材（中国語の問答）で、間が 200ms 前後の 2 人の発話が
   1 つのセグメントにつながった。候補チャンクの言語判定には影響しない。`chunking.min_ms = 1000` のつなぎ方は「間が 400ms 以内の同じ言語」に限る。
3. **`zh` と `yue` の確率の合算**（言語ペアに片方しかないとき、もう片方の確率を足す）と、**広東語のコースの既定のモデルを `large-v3` にする**こと
   （設計書 v0.5 の更新で反映済み）を、この ADR でも記録する。
4. 文字体系の確認では、日本語・韓国語・中国語の文に混ざるラテン文字（「Tシャツ」など）を不一致としない。平滑化で判定できなくなったチャンクは、
   平滑化の前の判定の言語で認識する（S1 後半で見つかった不具合の修正。transcriber のコミット `47a31da`）。

5. **`tools/transcriber/uv.lock` の取得元は公開の PyPI（`https://pypi.org/simple`）にする**（人間の判断。2026-10-14）。S1 前半の時点では、
   開発用の Mac の設定により社内のプロキシの URL が記録されていた（S1 前半 §8 の 1）。`pyproject.toml` の `[[tool.uv.index]]` で PyPI を明示し、
   `uv.lock` の `source` も PyPI になっている（main の c66f7a1 以降で対応済み）。

## 保留（人間のレビュー（言語の確認表）の後に決める）

S1 後半のレビュー用の表（`~/chunkflow-eval/review/*.review.csv`。リポジトリの外）に人間が正しい言語を記入し、`scripts/score_review.py` で
正解率を出してから決める。決めたら、この ADR を置き換える ADR を書く。

| 論点 | わかっていること | 候補 |
| --- | --- | --- |
| 平滑化の既定値 | 解説と学習言語が交互に並ぶ教材では、前後がもう一方の言語のことが多く、平滑化の変更の大半が誤った方向だった（hindi の turbo で 13 件中 9 件、large-v3 で 26 件中 15 件が `en` への変更） | `smoothing.low_conf = 0.0`（対象を 1 秒未満のチャンクに限る）+ `neighbor_weight = 0.25`（試算で変更が turbo 11 → 3、large-v3 16 → 0 件）。または平滑化をやめる |
| ヒンディー語の認識し直し（語彙の確認） | `en` と判定されローマ字で書かれたヒンディー語（turbo で約 80 件）を、`hi` を指定して認識し直すと 83 件中 73 件がデーヴァナーガリーで書けた。判定に英単語のリストが必要（試作は macOS の辞書を使用。Linux にはない） | 単語の頻度のリストを依存に加える（ライセンス・サイズの確認が必要。AGENTS.md §8）/ 別の手段（例: 言語判定の確率が低いときだけ両方で認識） |
| ヒンディー語のコースの既定のモデル | turbo は文の判定に自信を持って当てる（確率 0.8〜0.97）が短い語を `en` にしやすい。large-v3 は短い語に強いが、文の確率が低く（0.5〜0.7）平滑化に引かれやすい | turbo / large-v3 / 判定だけ turbo（`[model] detect`） |

## その他（別途判断が必要。この ADR では決めない）

- 学習言語の話者による指示（「말해보세요」「सुनिए और दोहराइए」）や、解説の中の発音例を含むチャンクの、言語フィルタ（F6.4）での扱い（仕様。ui・playback と M3 で決める）。
