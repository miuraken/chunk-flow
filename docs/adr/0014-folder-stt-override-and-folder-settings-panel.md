# 0014. フォルダ単位の音声認識エンジンの上書きと、フォルダの設定パネルの構成

- 状態: 承認済み
- 日付: 2026-10-23
- 決めた人: 人間（要望とモックアップ）、lead（設計の判断）、ui・audio-analysis（実装）
- 関係する節: 設計書 §6.3（テーブル）、§7.5.2（ライブラリ画面のフォルダの設定）。ADR 0011 §2.3（ファイルごとの上書き）と ADR 0013 §2（フォルダの色）を補う

## 背景

利用者から、ライブラリのフォルダの設定について、モックアップ付きで次の要望があった。

1. 見出しに Tune アイコンを置いて「設定」であることを示し、その隣の入力欄でフォルダ名を編集できるようにする。仮想フォルダなら名前の右に「仮想」バッジを出す。
2. その下に色の設定を置く。ふだんは 6 色、右の ▼ で 3 倍の色から選べる。デフォルトから変えたときは、デフォルトの色をグレーの ✓ で示す。ふだん隠れている色を選んだときは、閉じても選んだ色（とデフォルトの色）が見えるよう、選んだ色を左上に持ってくる。
3. 「全体設定（言語）」はボタンをやめ、案内文の中のリンクにする。
4. フォルダ単位でも、選んだ 2 言語の音声認識モデルを選べるようにする。**ファイル個別設定 ＞ フォルダ設定 ＞ 全体設定**の順にフォールバックする。ファイル個別設定では、入っているフォルダの設定が全体設定と違うときは「全体設定に従う」を「フォルダー設定に従う」と表示する。

## 決定

### 1. 保存のしかた（スキーマ 9）

- `course_folder` に `target_stt_engine` と `base_stt_engine`（どちらも `TEXT`、`NULL` 可）を足す。`NULL` はその言語の上書きなし。値は `SttEngine` の名前で、知らない名前は上書きなしとして読む。
- スキーマを 8 から 9 に上げる（`MIGRATION_8_9`。`ALTER TABLE ... ADD COLUMN` を 2 つ）。既存の行は上書きなしになる。テストは ADR 0013 §4 と同じ方式の `Migration8To9Test`。
- `CourseFolderDao.upsert` は、上書きの列がどちらも `NULL` の行を書くときは既存の値を残す（再スキャンなどで消さない）。消すときは `updateSttOverride(path, null, null)` を使う。
- `LibraryRepository.setCourseFolderSttOverride(coursePath, override)` で保存する。設定の行がないフォルダは、上書きがあるときだけ行を作る。フォルダの名前を変えたときは、新しいパスに保存し直し、古いパスの上書きは消す。
- モデルは `LibraryCourseFolder.sttOverride`（`ItemSttOverride`）。

### 2. エンジンの決め方

- **ファイル個別設定 ＞ フォルダ設定 ＞ 言語ごとの全体設定 ＞ 自動**の順にする。言語の役割（学習対象 / ベース）ごとに決める（`itemOverride.withFolderFallback(folderOverride)` のあと、ADR 0011 §2.2 の `SttEngineSelection`）。
- フォルダ設定は、**ファイルに近いフォルダから親へたどり**、役割ごとに最初に見つかった上書きを使う（`LibraryCourseFolder.resolveSttOverride`）。言語ペアを親フォルダで変えると中のすべてのファイルに効くのと同じく、エンジンの指定も中のフォルダのファイルに効かせる。
- フォルダの上書きは、フォルダの設定で選んだ言語ペアに対するエンジンの指定なので、**フォルダの言語とファイルの言語が同じ役割にだけ効かせる**（`LanguageSettings.normalize` でそろえて比べる。`LibraryCourseFolder.sttOverrideFor`）。言語を個別に変えたファイルや、親と違う言語のサブフォルダに、その言語で使えないエンジンが付くのを防ぐ。
- この決め方は core:model の 1 か所にまとめ、文字起こし（`DefaultAnalysisRepository`）、プレイヤーのファイルの設定（`PlayerViewModel`）、ライブラリ（`LibraryViewModel`）が同じ関数を使う。
- 色（ADR 0013 §2）はサブフォルダに引き継がないが、エンジンの指定は引き継ぐ。色はフォルダの見分けのため、エンジンは中のファイルの言語のための設定で、目的が違うため。

### 3. フォルダの設定パネル（`EditDirectoryMetadataDialog`）

上から次の順に並べる（モックアップのとおり）。

1. 見出し: Tune アイコン（飾り）と、フォルダ名を編集する入力欄。仮想フォルダなら名前の右に「仮想」バッジ。
2. 色（`FolderColorPicker`）: 1 行 6 色と ▼。▼ で 18 色（6 列 × 3 行）を開く。
   - 並びは `LibraryFolderColors.orderedPaletteIndices`。基準の選択は、シートを開いたときと、色を閉じたときに更新する（開いている間に押しても見本は動かない）。隠れている色を選んで閉じると、その色が左上に来て、デフォルトの色も 1 行目に入る。
   - 選んでいる色は濃い ✓ と太い枠。デフォルトから変えているときは、デフォルトの色にグレーの ✓。デフォルトの色を押すと指定を外す（対象言語の既定の色に戻す）。
   - 見出し・「デフォルトに戻す」ボタン・説明文は置かない（読み上げは「色 N」「色 N（デフォルト）」と選択状態で伝える）。
3. 言語（学習対象・ベース）と、案内文「設定したい言語が見つからないときは、⚙ 全体設定（言語） から追加してください。」。「全体設定（言語）」はリンク（押すと全体設定の言語タブを開く）。ボタンはやめる。この部品は取り込み・新規仮想フォルダ・ファイルの設定のダイアログと共通なので、そこもリンクになる。
4. 音声認識モデルの管理: 「全体設定に従う」のチェックと、言語ごとのアコーディオン（エンジンの選択、モデルの取得・削除）。チェックを外したときだけ選べる。
5. キャンセル / 保存、フォルダを削除。

### 4. ファイルの設定（プレイヤー）の表示

- 言語ごとのアコーディオンで、その言語にフォルダの上書きが効いているときは「全体設定に従う (エンジン)」を「フォルダー設定に従う (エンジン)」と表示し、括弧の中はフォルダで決まるエンジンにする。
- 「全体設定に従う」のチェックの文言は、どちらかの言語にフォルダの上書きが効いているときは「フォルダー設定に従う」にする。

## 影響

- パレットは 8 色から 18 色に増える（ADR 0013 §2 の 1 と 3 を置き換える。既存の 0〜7 番の色は変わらない）。対象言語の既定の色は 19 言語目から先頭の色に戻る。
- フォルダの設定のシート、ファイルの設定、designsystem のフォルダのパレットのスクリーンショットの基準画像が変わる（更新は人間の承認を得てから）。
- 設計書 §6.3 と §7.5.2 を更新する。
