# 0013. ライブラリのタグとフォルダの色分け

- 状態: 承認済み（§2 の 1・3 のパレットの色数〔8 色 → 18 色〕と色見本の並べ方は [ADR 0014](0014-folder-stt-override-and-folder-settings-panel.md) で置き換え）
- 日付: 2026-10-21
- 決めた人: 人間（要望）、lead（設計の判断）、実装担当（記録）
- 関係する節: 設計書 §6.3（テーブル）、§7.5.2（ライブラリ画面）

## 背景

利用者から、ライブラリについて次の 2 つの要望があった。

1. 各ファイルに設定画面などから「タグ」を付けられるようにする。ライブラリで複数の項目を選んで「タグを編集」から一斉に付け外しできるとよい。ファイルタブではタグでも絞り込めるようにする。
2. フォルダを対象言語によって薄く色分けする（色は決め打ちのリストから、追加された順番でよい）。フォルダの設定では、そのフォルダの色を指定でき、「デフォルトに戻す」で元の色に戻せる。

## 決定

### 1. タグ

1. **タグは自由入力の文字列**とし、Room のテーブル `tag`（`id`、`name`、`name_key`（一意）、`created_at`）と、ファイルとの対応 `media_item_tag`（`media_id` → `media_item`、`tag_id` → `tag`、どちらも CASCADE、主キーは 2 列）で持つ。ファイルを削除すると対応も消える。
2. 名前は `core:model` の `LibraryTags` でそろえる。
   - 前後の空白を除き、改行やタブを含む連続する空白を半角スペース 1 つにまとめ、NFC に正規化する。
   - 32 文字（コードポイント）まで。制御文字と、表示を乱す双方向テキストの制御文字（U+202A〜202E、U+2066〜2069）を含む名前は受け付けない。
   - 同じタグかどうかは `name_key`（NFKC で全角・半角をそろえて小文字にしたもの）で判定し、大文字・小文字や全角・半角だけが違うタグは 1 つにまとめる。表示は最初に作られたときの表記にする。
   - 1 つのファイルに付けられるタグは 30 個まで。
3. **どのファイルにも付いていないタグは削除する**（一覧や絞り込みに残さない）。タグの名前の変更や、タグそのものの削除の画面は作らない（選択モードの「タグを編集」で全ファイルから外せば消える）。
4. 付け外しの入口は 2 つ。
   - **ファイルの設定のシート**: 付いているタグのチップ（押すと外す）、新しいタグの入力欄、既存のタグから付けるチップ。「保存」で反映し、入力途中のタグも保存する。
   - **選択モードの「タグを編集」**: 選んだファイル（選んだフォルダの中のファイルを含む）に対して、既存のタグを一覧する。チェックは「すべてのファイルに付いている＝オン／一部＝中間（−）／なし＝オフ」で始まり、押すたびにオン → オフ →（中間で始まったものだけ）中間 と変わる。中間のままのタグは変えない。新しいタグも作れる（作ったタグはオン）。「適用」で付け外しをまとめて保存し、選択モードを終了する。同じタグを付けると外すの両方に指定したときは付ける。削除済みのファイルは飛ばす。
5. **ファイルタブの絞り込みは AND**（選んだタグをすべて持つファイルだけを出す）。タグが 1 つ以上あるときだけ、タグのチップの列を出す。絞り込みの結果が 0 件で、タグが原因のときは「選んだタグがすべて付いたファイルはありません」と表示し、タグの選択を解除する操作を出す。
6. タグは端末内のデータベースにだけ持ち、文字起こしの形式（`docs/format/`）には含めない。

### 2. フォルダの色

1. **決め打ちの 8 色のパレット**を `core:designsystem` に置く（`ChunkFlowFolderPalette`、`chunkFlowFolderPalette()`）。番号（0〜7）の決まりは `core:model` の `LibraryFolderColors` が持つ。
   - 色相は固定にし、ダイナミックカラーに調和させない（利用者が選んだ色がテーマで変わらないように）。最初に使われる番号ほど見分けやすいように、色相環を飛び飛びに並べる（青 → 橙 → 緑 → ピンク → 青緑 → 黄 → 紫 → 赤）。
   - ライトはトーン 92（選択中は 84）、ダークはトーン 22（選択中は 32）の薄い色にする。文字（`onSurface` / `onSurfaceVariant`）とのコントラスト比 4.5:1 以上、フォルダのアイコン（`primary` / `tertiary`）との 3:1 以上をテスト（`FolderPaletteTest`）で固定する。
2. **既定の色は対象言語ごと**に決める。対象言語が初めてフォルダに使われた順（0 始まりの順番）に、パレットの先頭から割り当てる。
   - 順番はテーブル `language_color`（`language` が主キー、`ordinal`）に保存し、**フォルダを消しても変わらない**。9 言語目からは先頭の色から繰り返す。
   - 言語コードは設定のカタログのコードにそろえる（区別のない `zh` は `zh-cn`）。
   - フォルダの設定の行を作る・更新するときに、まだ順番のない対象言語に次の順番を割り当てる。スキーマ 8 への移行では、既存の `course_folder`（行の順）、`media_item`（取り込んだ順）の順に割り当てる。
   - まだ順番のない対象言語は、次に割り当てられる順番の色で表示する。
3. **フォルダごとの指定**は `course_folder.color_index`（`null` なら既定の色）。フォルダの設定のシートで 8 色の色見本から選び、「デフォルトに戻す」で `null` に戻す。保存で反映する（キャンセルでは変えない）。
   - フォルダの名前を変えても指定を引き継ぐ。設定の行がないフォルダ（ファイルだけから見えているフォルダ）に色を指定するときは、行を作ってから設定する。
   - サブフォルダは親の指定を引き継がない（自分の指定か、自分の対象言語の色）。
4. フォルダの対象言語は、フォルダの設定の行の言語、なければフォルダの中の最初のファイルの言語とする。どちらもわからないフォルダは色を付けない（従来どおり `surfaceContainer`）。
5. フォルダの行と、開いているフォルダの見出しを薄く塗る。選択中の行は同じ色相の濃い色にし、チェックボックスでも選択を示す。**実フォルダ／仮想フォルダの区別は色に頼らない**（アイコンの色と「仮想」バッジで示す）。

### 3. 選択モードの上部バー

「タグを編集」を加えると操作が 5 つになり、アイコンと文字のボタンでは幅 411dp のスマートフォンに収まらない（従来の 4 つでも約 363dp が必要で、使える幅の約 355dp を超え、左の × ボタンに重なり得た）。そこで、**幅が足りるとき（タブレットなど）だけアイコンと文字のボタンにし、足りないとき（スマートフォンや文字サイズが大きいとき）はアイコンだけのボタン**にする（長押しで名前のツールチップ、読み上げは名前。`LibrarySelectionActions`）。

### 4. スキーマ

- Room のスキーマを 8 に上げる（`MIGRATION_7_8`。`course_folder.color_index`、`language_color`、`tag`、`media_item_tag` を追加）。
- `MigrationTestHelper` は依存（`room-testing`）を追加しないため使わない。エクスポート済みの `7.json` の SQL で v7 のデータベースを作り、Room で移行して検証する同等のテスト（`Migration7To8Test`）にした（lead の判断）。

## 影響

- `LibraryRepository` に、フォルダの色（`setCourseFolderColor`、`observeFolderLanguageColorOrdinals`）とタグ（`observeTags`、`observeItemTags`、`setItemTags`、`updateItemTags`）の API を加える。`FakeLibraryRepository` も同じ決まりで持つ。
- 設計書 §6.3 と §7.5.2 を更新する。
- ライブラリの画面の基準画像が変わる（フォルダの行と見出しの色、新しい画面の画像）。マージの前に人間の承認を得る（ADR 0002）。
- 見送ったこと: タグの名前の変更・統合の画面、タグのエクスポート・インポート、親フォルダの色の引き継ぎ。
