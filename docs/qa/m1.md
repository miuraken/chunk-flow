## 3. 設計書・ADR・セキュリティ要件に対する詳細レビュー結果

### 3.1 F1.1: SAF 音声ファイル取り込み（`core:data`、§7.1、§8.1、ADR 0008）

- **フォーマット検証とメタデータ抽出（[`AudioFormatInspector`](../../core/data/src/main/kotlin/com/miuraken/chunkflow/core/data/library/AudioFormatInspector.kt)）**:
  - `MediaExtractorCompat` でトラックを走査し、`mime.startsWith("audio/")` の音声トラックが存在しないファイルは `ImportError.UnsupportedFormat` として拒否し、例外を UI に漏らさない。
  - `MediaMetadataRetriever` と `MediaFormat` の双方から再生時間・サンプルレート・チャンネル数・タイトルを取り出し、`durationMs <= 0L` の破損ファイルも `ImportError.UnsupportedFormat` として安全に拒否する。
  - [`Mp3HeaderParser`](../../core/data/src/main/kotlin/com/miuraken/chunkflow/core/data/library/Mp3HeaderParser.kt) で ID3v2 タグを読み飛ばし、先頭フレームの MPEG バージョン・レイヤ・サンプルレート・CBR/VBR ヘッダ（`Xing` / `Info` / `VBRI`）および LAME Info タグの encoder delay / padding を解析している。
  - ADR 0008（設計書 §7.3.1 / §7.4.6）に従い、MP3 で LAME Info タグまたは `Xing`/`Info` ヘッダがある場合は `+25ms`（529 サンプルのデコーダ遅延差）、ヘッダがない素の MP3 では MPEG-1 Layer III `+65ms` / MPEG-2・2.5 Layer III `+40ms`、MP3 以外は `0ms` を `calculateInitialTranscriptOffsetMs` で算出し、新規項目の `ItemStateEntity.transcriptOffsetMs` に保存している。
- **ファイル配置・重複検出・セキュリティ境界（[`MediaFileLocator`](../../core/data/src/main/kotlin/com/miuraken/chunkflow/core/data/library/MediaFileLocator.kt)、[`DefaultLibraryRepository`](../../core/data/src/main/kotlin/com/miuraken/chunkflow/core/data/library/DefaultLibraryRepository.kt)）**:
  - `uri.scheme != ContentResolver.SCHEME_CONTENT` の URI を拒否し、`file://` 等によるアプリ内部領域への誘導を防止している（§8.1）。
  - コピー前とコピー中の双方で `MAX_AUDIO_FILE_BYTES = 2 GB` 上限と `StatFs.availableBytes >= expected * 1.2`（不明時は最低 50 MB）の空き容量検査を行い、上限超過やエラー時は `staging/` の一時ファイルを `finally` で確実に削除する（§7.1、§8.1）。
  - ストリーミングコピーと同時に `MessageDigest.getInstance("SHA-256")` を計算し、同一 SHA-256 の教材が既に DB に存在する場合は：
    1. 音声ファイルが端末内に存在する場合は重複コピーを破棄して既存項目を返し（F1.1 重複検出）、
    2. 自動バックアップからの復元後で `localPath` が未設定または実ファイル欠損（`SOURCE_MISSING`）の場合は、新しい音声ファイルを既存の `mediaId` に紐付けて `transcript_segments`（`userEdited = true` を含む）・`bookmarks`・`item_state` をすべて維持する（§6.4、F2.4）。
  - `isSafeIdentifier`（UUID 形式の厳密検証）と `canonicalFile` による `isChildOf(filesDir/media)` 検査により、パストラバーサルを二重に防止している。
  - ファイル表示名は `sanitizeDisplayName` でパス区切り文字・制御文字・先頭ドットを除去し、最大 200 文字に切り詰めている。また、外部入力境界に `TODO(security)` コメントが付与されている。

### 3.2 F2.1 / F2.2: ライブラリ一覧とレジューム保存・復元（`core:database`、`core:playback`、`feature:library`）

- **位置と速度の保存タイミング（[`MediaControllerPlaybackController`](../../core/playback/src/main/kotlin/com/miuraken/chunkflow/core/playback/MediaControllerPlaybackController.kt)、§7.2.5）**:
  - 再生中（`isPlaying == true`）のみ `POSITION_SAVE_INTERVAL_MS = 5_000L` ごとに `itemStateDao.updatePlaybackPosition(mediaId, positionMs, updatedAtEpochMs)` を実行し、位置が変化していない場合は無駄な DB 書き込みを行わない。
  - 一時停止（`pause()`）、停止（`stop()`）、別教材への切り替え（`open()` 冒頭の `flushCurrentPosition()`）、速度変更（`setSpeed()`）、再生終了（`STATE_ENDED`）、プレイヤーエラー時に即座に現在位置を DB へフラッシュする。
- **状態復元（レジューム）と `onPlaybackResumption`**:
  - `open(mediaId)` で `ItemStateEntity` から `lastPositionMs`・`playbackSpeed`・`practiceSettings` を復元し、シーク位置が音声長を超える場合は `coerceIn(0L, durationMs)` で安全に丸める。
  - 設計書 §7.2.5 の規定（「ループの範囲はアプリを再起動したら解除する」）に従い、`open()` および `prepareForResumption()` 時は常に `LoopMode.Off` にリセットしている。
  - `PlaybackService.PlaybackSessionCallback.onPlaybackResumption` で `playbackController.prepareForResumption()` を呼び出し、最後に再生・更新された教材の `MediaItemsWithStartPosition` を返してシステム UI や Bluetooth イヤホンからの再開に対応している。
  - 実ファイルが欠損している場合はクラッシュせず `PlaybackStatus.Error(PlaybackError.SourceMissing)` を通知し、`LibraryScreen` でも「音声なし」バッジを表示する。

### 3.3 F3.1 / F3.2 / F3.3: 再生・速度・スキップ・バックグラウンド（`core:playback`、`feature:player`、ADR 0006 / 0007）

- **ExoPlayer の構成（[`PlaybackPlayerFactory`](../../core/playback/src/main/kotlin/com/miuraken/chunkflow/core/playback/PlaybackPlayerFactory.kt)、§7.2.2）**:
  - `AudioAttributes`: `USAGE_MEDIA` + `AUDIO_CONTENT_TYPE_SPEECH`、`handleAudioFocus = true`（電話着信・他アプリ再生時の一時停止と復帰）。
  - `setHandleAudioBecomingNoisy(true)`（イヤホン切断時の自動一時停止）。
  - `setWakeMode(C.WAKE_MODE_LOCAL)`（画面オフ再生中の CPU スリープ防止）。
  - `experimentalSetDynamicSchedulingEnabled(false)`（ADR 0007: 画面オフ時を含むチャンク終端・ループ境界の監視精度確保）。
  - `DefaultExtractorsFactory().setMp3ExtractorFlags(Mp3Extractor.FLAG_ENABLE_INDEX_SEEKING)` と [`IndexSeekDataSource`](../../core/playback/src/main/kotlin/com/miuraken/chunkflow/core/playback/IndexSeekDataSource.kt)（ADR 0006: MP3 の先頭フレームにある `Xing` / `Info` / `VBRI` の TOC を `XXXX` にマスクして `IndexSeeker` を強制し、100 個の荒いジャンプ表による最大 18 秒のシークずれを解消）。
- **`LearningPlayer`（[`LearningPlayer`](../../core/playback/src/main/kotlin/com/miuraken/chunkflow/core/playback/LearningPlayer.kt)、§7.2.3）**:
  - `ForwardingSimpleBasePlayer` を継承し、`getState()` で `COMMAND_SEEK_TO_PREVIOUS` / `COMMAND_SEEK_TO_NEXT` / `COMMAND_SEEK_BACK` / `COMMAND_SEEK_FORWARD` / `COMMAND_SET_SPEED_AND_PITCH` 等を公開するとともに、VBR MP3 で `IndexSeeker` が初期推定値を返す間も Room に保存済みの `knownDurationMs` を優先して通知・シークバーのぶれを防いでいる。
  - `handleSeek` で、チャンク一覧がある場合は前後のチャンク頭（開始から 1 秒以上経過時は現在チャンク頭）へ移動し、チャンクが空（M1 または解析前）の場合は設定された巻き戻し / 早送り秒数（`seekBackMs` / `seekForwardMs`）へフォールバックする。
- **`PlaybackService` のセキュリティ境界（[`PlaybackService`](../../core/playback/src/main/kotlin/com/miuraken/chunkflow/core/playback/PlaybackService.kt)、§8.1）**:
  - `isTrustedController` で自アプリ（`packageName` または `Process.myUid()`）、`Process.SYSTEM_UID`、および `controller.isTrusted` のみを信頼済みと判定する。
  - 信頼されていない外部コントローラに対しては、`onConnect` でカスタム `SessionCommands` を空（`SessionCommands.EMPTY`）にして標準の再生コマンドのみを許可し、`onCustomCommand` が直接呼ばれた場合も `SessionResult(SessionError.ERROR_PERMISSION_DENIED)` で拒否する（[`PlaybackServiceAndFactoryQaTest`](../../core/playback/src/test/kotlin/com/miuraken/chunkflow/core/playback/PlaybackServiceAndFactoryQaTest.kt) で検証済み）。
- **再生位置の分離と再コンポーズ防止（[`PlayerScreen`](../../feature/player/src/main/kotlin/com/miuraken/chunkflow/feature/player/PlayerScreen.kt)、[`PlayerViewModel`](../../feature/player/src/main/kotlin/com/miuraken/chunkflow/feature/player/PlayerViewModel.kt)、§6.2）**:
  - `PlayerUiState.Ready` は高頻度に変化する `positionMs` を一切保持せず、`PositionProvider` を `PlayerScreen` 内の最小スコープ（`PlayerProgressSection`）でのみ `collectAsStateWithLifecycle(initialValue = 0L)` している。これにより 16ms〜50ms 周期の位置更新で画面全体（TopAppBar、タイトル、再生ボタン、速度シート等）が再コンポーズされない構造になっている。

### 3.4 F9.1: 設定と永続化（`core:datastore`、`feature:settings`）

- [`DataStoreUserSettingsRepository`](../../core/datastore/src/main/kotlin/com/miuraken/chunkflow/core/datastore/DataStoreUserSettingsRepository.kt) で `seekBackMs`（1〜30 秒）、`seekForwardMs`（1〜30 秒）、`defaultSpeed`（0.5x〜2.0x、0.05 刻みに丸め）、`defaultLanguagePair`（`target` と任意指定の `base`、単一言語教材では `base = null`）、`chineseScript`（`HANS` / `HANT`）、`cantoneseScript`（`HANT` / `HANS`）を Preferences DataStore に保存し、`IOException` 時は `emptyPreferences()` にフォールバックしている。
