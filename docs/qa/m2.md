## 6. 人間に依頼する実機手動テスト項目（品質ゲート 4、`docs/manual-test.md` §3）

[`docs/manual-test.md`](../manual-test.md) の「3. M2: チャンクプレイヤー = MVP」に記載の以下の項目は、Pixel 実機・Bluetooth イヤホン・画面オフ（Doze / WakeLock）を伴うため、実機での確認対象として記録します。

1. **M2-1 / M2-2**: 30 分の音声を取り込んだ直後に再生でき、Pixel 実機で 60 秒以内に波形とチャンクが生成されること。
2. **M2-3 / M2-4**: 拡大波形が滑らかに追従し、タップ・スクラブ・ピンチ・長押しドラッグ A-B 選択および分割パラメータのスライダー即時反映が動作すること。
3. **M2-6**: 発話とハイライトのずれが耳で聞いて違和感ないこと（50ms 未満）。
4. **M2-9**: 画面オフ状態で Bluetooth イヤホンの前後ボタンによりチャンク頭へ移動できること。
5. **M2-10**: 0.5x / 1.0x / 2.0x の各速度で、終端 B の行き過ぎ（次のチャンクの語頭漏れ）がないこと。
6. **M2-11**: 充電器を外して画面オフで固定秒数・チャンク長比例の自動ポーズを有効にした際、期限付き `PARTIAL_WAKE_LOCK` により設定どおりのポーズ長で再開すること。
