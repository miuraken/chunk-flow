# 手動テスト手順書（Pixel 実機・エミュレータ）

本書は、自動テスト（単体テスト・Robolectric・スクリーンショットテスト）では検証しきれない、実機固有の挙動（Bluetooth イヤホン、画面オフ・ロック画面・Doze、ハードウェアデコーダ、Google Drive 連携、電池消費など）を各マイルストーンの品質ゲートで確認するためのチェックリストです（設計書 §9、§10.5.3、§11）。

- **対象端末**: Pixel 8 以降（Android 14 / API 34 以上）
- **記録方法**: 各マイルストーンの品質ゲート報告（`docs/qa/<マイルストーン>.md`）に、実施した項目・端末名・OS バージョン・結果（PASS / FAIL / 未確認）を記録する。

---

## 0. 事前準備（共通）

1. 開発用 Mac から USB またはワイヤレスデバッグで実機（またはエミュレータ）が `adb devices` に表示されることを確認する。
2. デバッグビルドをインストールして起動する:
   ```sh
   JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" \
     ANDROID_HOME="$HOME/Library/Android/sdk" \
     ./gradlew :app:installDebug
   adb shell am start -n com.miuraken.chunkflow/.MainActivity
   ```
3. Phase 0 の技術検証（スパイク S2 / S3）の実機計測を行う場合は、[`docs/spikes/README.md`](spikes/README.md) の「実機待ち・人間の作業待ちの計測」（D1〜D12、H1〜H4）の手順に従う。

## 1. Phase 0: 骨格の起動と画面遷移の確認

Phase 0 の完了条件（§11「空の画面の間を遷移できる」）および targetSdk 36 の基本表示を確認する。

- [ ] **P0-1 起動と初期表示**: アプリを起動し、クラッシュせずにライブラリ画面（空の状態）が表示されること。システムバー（ステータスバー・ナビゲーションバー）と TopAppBar が重ならず edge-to-edge で表示されること。
- [ ] **P0-2 ライブラリ → プレイヤー遷移と戻る操作**: ライブラリ画面の「プレイヤー画面を開く（確認用）」ボタンをタップしてプレイヤー画面に遷移し、左上の「戻る」ボタンおよびシステムの戻るジェスチャー（予測型「戻る」）でライブラリ画面に戻れること。

- [ ] **P0-4 画面回転・テーマ切り替え**: 縦向き・横向き、およびダークテーマ・ライトテーマを切り替えてもクラッシュせず、現在の画面（バックスタック）が維持されること。

## 2. M1: 使えるプレイヤー（取り込み・再生・バックグラウンド・レジューム）

M1 の完了条件（§11「Pixel 実機で Drive / ローカルの教材を取り込み、画面オフで 1 時間再生できる。プロセスが終了しても再生位置を復元できる」）を確認する。

### 2.1 ファイル取り込み（SAF: ローカル / Google Drive）

- [ ] **M1-1 ローカル音声の取り込み（F1.1）**: SAF ピッカーから端末内の音声ファイル（MP3 / M4A / Ogg Opus / FLAC / WAV）を選択し、進捗表示の後にライブラリ一覧へ追加され、1 秒未満で再生を開始できること（§3）。
- [ ] **M1-2 Google Drive からの SAF 取り込み（F1.1、S2 H1）**: SAF ピッカーの「ドライブ」から Google Drive 上の音声ファイルを選択して取り込めること。機内モード（オフライン）で未キャッシュのファイルを選んだ場合はクラッシュせず案内メッセージが表示されること（§7.1）。
- [ ] **M1-3 重複取り込みの検出**: 同じ音声ファイルを再度取り込んだとき、SHA-256 で重複が検出され、既存の項目が開かれること（§6.4、§7.1）。
- [ ] **M1-4 不正ファイルの拒否（§8.1、§9）**: 破損したファイルや音声トラックのないファイル（拡張子だけ `.mp3` にしたテキストなど）を選択したとき、クラッシュせずエラーが表示され、`filesDir/media/` にゴミファイルが残らないこと。
- [ ] **M1-5 教材の削除（F2.1）**: ライブラリから教材を削除したとき、一覧から消え、`filesDir/media/` 内の音声ファイルも削除されること。

### 2.2 再生・シーク・速度・スキップ

- [ ] **M1-6 基本操作と MP3 シーク精度（F3.1、ADR 0006、S2 D5）**: CBR・VBR（Xing ヘッダあり / なし）の MP3 および M4A で、再生 / 一時停止、シークバー操作が正しく動くこと。30 分・60 分の MP3 で後半へ初めてシークした際の待ち時間が実用上問題ないか確認すること（§13）。
- [ ] **M1-7 再生速度とスキップ（F3.2、F3.3）**: 速度を 0.5x〜2.0x（0.05 刻み・プリセット）に変更してもピッチが変わらず自然に聞こえること。巻き戻し（既定 3 秒）・早送り（既定 5 秒）が設定どおり動くこと。
- [ ] **M1-8 Layout Inspector での再コンポーズ確認（§6.2、§10.5.3）**: Android Studio の Layout Inspector で再生中の再コンポーズ回数を確認し、再生位置の更新によって画面全体が再コンポーズされていないこと。

### 2.3 バックグラウンド再生・通知・ロック画面・オーディオフォーカス

- [ ] **M1-9 バックグラウンド・画面オフでの 1 時間連続再生（§11 M1、S2 D8）**: 画面をオフにして 1 時間再生し続け、途中で止まらないこと。あわせて `experimentalSetDynamicSchedulingEnabled(false)`（ADR 0007）による電池消費に異常がないか確認すること。
- [ ] **M1-10 メディア通知とロック画面の操作（F3.1、§7.2.6）**: 通知シェードおよびロック画面のメディアコントロールにタイトルと再生状態が表示され、再生 / 一時停止 / 前後ボタンが操作できること（`POST_NOTIFICATIONS` 権限を拒否していてもメディア通知が出ること）。
- [ ] **M1-11 イヤホン抜け（Becoming Noisy）とオーディオフォーカス（§7.2.2）**: 再生中に Bluetooth イヤホンを切断（または有線イヤホンを抜く）したときに自動で一時停止すること。電話の着信や他アプリのメディア再生が始まったときに一時停止すること。

### 2.4 レジューム（状態復元）

- [ ] **M1-12 プロセス終了後のレジューム（F2.2、§11 M1）**: 再生位置・速度を変更したあと、`adb shell am kill com.miuraken.chunkflow`（またはタスク一覧からスワイプ終了）してアプリを再起動し、教材を開くと前回の再生位置と速度が復元されること。システムのメディアコントロールからの再開（`onPlaybackResumption`）も動作すること（§7.2.5）。

## 3. M2: チャンクプレイヤー = MVP（解析・波形・文字起こし取り込み・学習モード・イヤホン）

M2 の完了条件（§11）を確認する。

### 3.1 音声解析・波形・自動チャンク分割

- [ ] **M2-1 取り込み直後の即時再生（G1、D1）**: 30 分の教材を取り込んだ直後、波形・チャンク解析がバックグラウンドで実行されている最中でも待たずに再生・シークができること。
- [ ] **M2-2 Pixel 実機での解析速度とメモリ（§3、§11 M2、S3 D1〜D4）**: Pixel 実機で 30 分の音声の波形とチャンクが 60 秒以内に生成されること。アプリを背面に回してもフォアグラウンドサービス（`mediaProcessing` / `dataSync`）として解析が止まらず完了すること（§7.3.4）。FLAC ファイルでも無限ループせず正常に完了すること（ADR 0005）。
- [ ] **M2-3 全体波形と拡大波形の操作（F4.1、F4.2、§7.5.4）**: 全体波形の下に現在位置の前後 2 分の拡大波形が表示され、60fps で滑らかに追従すること。タップでシーク、横ドラッグでスクラブ、ピンチでズーム範囲変更、長押し＋ドラッグで A-B 範囲選択ができること。画面端でのドラッグがシステムの「戻る」ジェスチャーに奪われないこと。
- [ ] **M2-4 分割パラメータの即時プレビュー（F5.2）**: 分割パラメータのスライダーを動かしたとき、再デコードなしで即座にチャンク境界が更新されること。

### 3.2 PC ツールの文字起こし取り込みとスクリプト表示

- [ ] **M2-5 音声と文字起こし JSON の一括・単独取り込み（F1.2、F1.3）**: PC ツールで作った `*.chunkflow.json` を音声と同時に（または後から単独で）取り込み、SHA-256 で対応付けられてチャンクとスクリプトが表示されること。
- [ ] **M2-6 スクリプトと再生位置の同期（F7.1、§11 M2、S2 D12）**: 再生位置に合わせて現在のチャンクが強調・自動スクロールされ、発話とハイライトのずれが 50ms 未満（耳で聞いて違和感がないこと）であること。手動スクロール中は自動追従が止まり「現在位置へ戻る」ボタンが出ること。
- [ ] **M2-7 多言語表示とブラインドモード（F7.2、§7.5.5）**: 日本語・韓国語・中国語（簡体字 / 繁体字の切り替え）・広東語（口語）・ヒンディー語（デーヴァナーガリー）・ロシア語・ギリシャ語・ベトナム語（声調記号）が正しい字形で折り返して表示されること。ブラインドモードでテキストが伏せられ、タップで一時表示できること。
- [ ] **M2-8 チャンクの出どころ切り替え（F5.4）**: 文字起こし由来のチャンク（`IMPORTED`）と端末内の自動分割（`AUTO`）を切り替えられること。
- [ ] **M2-12 停止中のチャンクタップ単発再生（F6.1、§7.5.2、§7.5.5）**: 再生停止（一時停止）中にチャンクリストの項目をタップすると、そのチャンクの頭から再生が開始されること。そのチャンクにリピートチェックが付いていればユーザーが止めるまで無限リピートされ、付いていなければ 1 回だけ再生してチャンク終端で自動停止すること。

### 3.3 チャンク移動・リピート・A-B・自動ポーズ・イヤホン操作

- [ ] **M2-9 Bluetooth イヤホンの前 / 次ボタンによるチャンク移動（F3.4、§11 M2、S2 D10）**: 画面オフの状態で Bluetooth イヤホンの「次へ」ボタンで次のチャンクの頭へ、「前へ」ボタンで現在のチャンクの頭（開始から 1 秒以上経過時）または前のチャンクの頭（1 秒未満時）へ移動できること。
- [ ] **M2-10 チャンクリピート・範囲リピート・A-B リピートの精度（F6.1、F6.2、§11 M2、S2 D7）**: 単一チャンク・連続する複数チャンク・A-B 範囲のリピート（回数指定 / 無限）で、終端 B の行き過ぎが 50ms 未満（次のチャンクの語頭が聞こえないこと）であること。0.5x / 1.0x / 2.0x の各速度で確認すること。
- [ ] **M2-11 画面オフでの自動ポーズと再開精度（F6.3、§11 M2、S2 D9）**: 充電器を外して画面をオフにし、固定秒数およびチャンク長比例（`Proportional`）の自動ポーズを有効にして再生したとき、CPU スリープで再開が大幅に遅れることなく（期限付き `PARTIAL_WAKE_LOCK` により）設定したポーズ長で再開すること。ポーズ中にイヤホンや画面で操作したときはタイマーが取り消されること。
- [ ] **M2-13 チャンクごとのリピートチェックボックス（選択リピート）（F6.1、§7.5.2、§7.5.5）**: 各チャンク右端のチェックボックスで複数のチャンク（`repeatChunkIds`）を選択したとき、選択されたチャンクが開始時刻順に連続してリピート再生されること。

## 4. M3: 言語を使った学習と Google Drive 手動同期

M3 の完了条件（§11）を確認する。

- [ ] **M3-1 言語フィルタ再生（F6.4、§11 M3）**: 「学習言語のみ」「母語のみ」を選び、画面オフでも対象言語のチャンクだけが連続して再生されること。手動でシークしたときはその位置を優先し、次の境界からフィルタが適用されること（§7.2.4）。
- [ ] **M3-2 瞬間作文モード（F6.5、§11 M3）**: 母語（`base`）のチャンクの終端でのみ自動ポーズが入り、学習言語（`target`）のチャンクの後はポーズせずに進むこと（画面オフでも同様に動くこと）。
- [ ] **M3-3 手動言語バッジトグル・キャッシュ・強制再文字起こし（優先キュー）（F7.3、F7.4、§7.4.6、§7.5.5、ADR 0010）**:
  - 未検出チャンクの言語バッジが `-` と表示され、タップで学習言語 / 母語をトグルして再認識でき、言語フィルタと瞬間作文モードにも即座に反映されること。
  - 一度認識した言語の結果はアプリ起動中メモリにキャッシュされ、再度トグルしたときに再認識せず即座に切り替わること。
  - チャンク長押しメニューの「再度、文字起こしする」でキャッシュを破棄して強制的に再文字起こしできること。
  - 先読み文字起こしが進行中に言語トグルや「再度、文字起こしする」を実行した際、先読みキューより優先して先に処理されること。
- [ ] **M3-4 文字起こし時刻のずれ補正（F7.6、ADR 0008、S3 D6）**: MP3（LAME ヘッダあり / なし）および他形式で取り込み時の初期オフセットと自動補正（±500ms）が働き、さらに手動（10ms 単位）でも微調整できること。
- [ ] **M3-5 SRT / WebVTT / LRC の取り込み（F1.4）**: 外部の字幕ファイルを取り込み、HTML や WebVTT のタグが解釈されずプレーンテキストとして安全に表示されること（§8.1）。
- [ ] **M3-6 Google Drive の手動同期（F1.5、§11 M3、S2 H2）**: ライブラリ画面の「同期」ボタンから Google Play 開発者サービスの認可画面（初回のみ）を経て、Drive の `ChunkFlow/<コース>/` 直下の新しい音声と `transcription/*.chunkflow.json` がコース名付きで取り込まれること。2 回目以降は差分のみダウンロードされること。認可を取り消した状態や機内モードでもクラッシュせずエラーが表示されること。
- [ ] **M3-7 オンデバイス先読み文字起こしと量子化 Whisper Tiny 2 言語判定（F9.1、F10.2、§7.4.6、ADR 0010）**: 文字起こし JSON がない 2 言語混在教材（例: 日本語＋韓国語）で先読み文字起こし（設定画面で ON/OFF 切替、既定 ON）が動作し、チャンクごとに母語と学習言語が自動識別されて文字起こしされること。
- [ ] **M3-8 言語役割別の統一カラーパレットと読み方ガイド表示（F7.1、F9.1、§7.5.5）**:
  - 母語（青系）・学習言語（ピンク系）の配色がスクリプト一覧、拡大波形のチャンク領域背景、ライブラリ・設定画面の言語バッジに統一して適用されていること。
  - 非ラテン文字の学習言語で読み方ガイド（ローマ字 / Pinyin / Jyutping / IAST 等）の ON/OFF が機能し、中国語・広東語が選択されたときのみ簡体字・繁体字の切り替え設定が表示されること。

## 5. M4: 編集・バックアップ・大画面・アクセシビリティ

M4 の完了条件（§11）を確認する。

- [ ] **M4-1 チャンクの手動編集と文字起こしの引き継ぎ（F5.3、F7.4、§11 M4）**: チャンクの分割・結合・境界ドラッグおよびテキストの手動修正を行い、その後に再分割や文字起こしの再取り込みを行っても、手動修正したテキスト（`userEdited = true`）が消失せず引き継がれること（§6.4、§7.4.6）。
- [ ] **M4-2 ブックマークと書き出し（F8.1、F7.5）**: チャンクをブックマークし、再分割後も時刻基準で保持されること。ブックマークしたチャンクだけの連続再生、および SRT / LRC / TXT への書き出しができること。
- [ ] **M4-3 カラオケ表示（F7.7）**: `words` を持つ教材で単語単位のハイライトが再生位置に追従すること（中国語・広東語で別の字体を表示している場合も含む。§7.5.5）。
- [ ] **M4-4 自動バックアップからの復元（F2.4、§6.4、§8.2、§11 M4）**: `adb shell bmgr backupnow com.miuraken.chunkflow` とアンインストール・再インストール（または `bmgr restore`）で DB と設定だけが復元され（音声ファイルはバックアップに含まれないこと）、起動時に「音声なし」と表示されること。同じ音声を再度取り込むと SHA-256 で結び付き、文字起こし・手動修正・ブックマーク・再生位置がすべて元に戻ること。
- [ ] **M4-5 大画面 2 ペイン表示（§7.5.1、§7.5.6）**: タブレット（または折りたたみ展開時・横向き Expanded 幅）でライブラリとプレイヤー、およびプレイヤー内の「波形 + 操作部」と「スクリプト」が 2 ペインで表示されること。
- [ ] **M4-6 アクセシビリティ（§3、§7.5.4、§7.5.5、§11 M4）**:
  - TalkBack を有効にし、すべてのボタン・チャンク行・波形（`progressBarRangeInfo` と `customActions`）が音声で読み上げられ操作できること。
  - 端末の文字サイズを最大（2.0 倍）にしても文字切れや操作不能な重なりが起きないこと。
  - 言語バッジが色だけでなく文字（`KO` / `JA` など）でも判別でき、すべてのタップ領域が 48dp 以上あること。
